# TrustHire

AI-powered student referral platform connecting candidates with trusted professionals.

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Node.js
- Express
- MongoDB

## Features
- Referral system
- Dashboard
- Authentication
- Job tracking
- Recruiter insights

## Setup

```bash
npm install
npm run dev
```

---

## Deployment

Frontend:
```bash
Deploy on Vercel
```

Backend:
```bash
Deploy on Render or Railway
```

## Environment Variables

Create a `.env` file in backend:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```
